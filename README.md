### 🔐 Secrets Manager

[**View repository / Ver repositorio**](https://github.com/elpapu38/secrets-manager)

A local command-line password manager with an interactive menu. It stores encrypted credentials in a SQLite database on the user's own computer, without cloud storage or account synchronization.

## 🧪 Personal Projects & Experiments | Proyectos personales y experimentos

### 🔐 Secrets Manager — Local Password Manager

A personal password manager built around local storage and privacy.

The project uses **Node.js, TypeScript, SQLite, and encryption** to explore secure local credential management without cloud synchronization.

Areas explored include:

- 🔒 Encrypted local data storage.
- 🗄️ Persistent storage with SQLite.
- 🔑 Master-password-based access.
- 📋 Credential management and data export.

**En español:** Gestor personal de contraseñas basado en almacenamiento local y privacidad. Utiliza Node.js, TypeScript, SQLite y cifrado para explorar la administración segura de credenciales sin sincronización en la nube.

Entre las áreas trabajadas se encuentran el almacenamiento cifrado, la persistencia de datos, el acceso mediante contraseña maestra y la administración y exportación de credenciales.

### 🤖 Discord Bot — Music & Utilities

A personal Discord bot developed for use with friends, combining music features, gaming utilities, and interactive commands.

The project explores Discord integrations, command handling, database persistence, and an in-server economy system.

**Focus:** Node.js, TypeScript, Discord.js, SQLite, and bot development.

**En español:** Bot personal de Discord para utilizar con amigos, con funciones musicales, utilidades relacionadas con videojuegos y comandos interactivos.

El proyecto explora integraciones con Discord, gestión de comandos, persistencia de datos y un sistema de economía dentro del servidor.

### 🧟 Zombie Survival Game — Godot

A 2D zombie survival game project inspired by simulation and survival gameplay.

**Focus:** Godot, game design, gameplay systems, and 2D development.

Es una oportunidad para explorar sistemas de juego, mecánicas, diseño y el desarrollo de un videojuego con recursos gráficos y animaciones propias.
